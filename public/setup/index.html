Lumen Setup

Use this page on the TV laptop with a mouse and keyboard. Everything here can also be done from the iPhone remote.

1 · TMDB API key

  1. Create a free account at themoviedb.org/signup and confirm your email.
  2. Open themoviedb.org/settings/api → Create → Developer. Describe it as “personal TV interface”, non-commercial.
  3. Copy either the API Key or the API Read Access Token and paste it below.

2 · Background picture

Upload a JPEG, PNG or WebP. It becomes the background immediately (switch styles in Settings on the TV).

3 · Website tile

Adds a tile to Free to Watch that opens the site full screen.

4 · Watch button link

Every film gets a Watch button that opens this address with the film’s name added — lowercase, spaces as “-”. a / is added at the end. movies.com opens movies.com/the-dark-knight/. Opens full screen in Brave (ad blocker on) if Brave is installed. Write {name} to put the name mid-address and {year} for the year. Leave empty and Watch does nothing.
